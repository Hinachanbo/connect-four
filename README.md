# Connect Four

**Date:** 2025/9/9

## 実装概要
AI対戦ができるコネクトフォーです。AIは3種類の強さから選択できます。

![ゲーム画面](screenshot.png)

## 使用した技術
- React
- Redux
- Bootstrap
- Minimax法やMCTSといった探索アルゴリズム

## 機能説明
それぞれのAIのアルゴリズムは以下の通りです。

- **初心（弱い）**：自分と相手の1手先の勝敗を判断し、必勝の場所や置かなければ必負の場所に置く。そのような場所がなければ、ランダムに置く。
- **雀豪（普通）**：3手先（相手の手を含めると6手先）までの状況をMinimax法で評価関数を用いて評価する。
- **魂天（強い）**：MCTSで10000回シミュレーションする。

## ファイル構成
- `App.js`：メインコンポーネント
- `Board.js`：盤面の操作
- `Header.js`：タイトル・ルールモーダルの表示
- `config.js`：列、行の定数
- `store.js`：Redux部分
- `utils/`：AIアルゴリズム・勝敗判定
